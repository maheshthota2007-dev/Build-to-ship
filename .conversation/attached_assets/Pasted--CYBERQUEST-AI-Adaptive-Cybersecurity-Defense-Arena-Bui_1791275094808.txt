# CYBERQUEST AI

## Adaptive Cybersecurity Defense Arena

Build a complete, production-quality full-stack web application called **CyberQuest AI**.

### Hackathon Problem Statement

Create an interactive learning platform with cybersecurity lessons, quizzes, challenges, progress tracking, and leaderboards.

### Our Solution

CyberQuest AI transforms traditional cybersecurity learning into an interactive, gamified defensive training experience.

Instead of only reading lessons and answering basic quizzes, users become **Cyber Defenders** who investigate simulated cybersecurity incidents, make security decisions, receive AI-powered feedback, earn XP and badges, improve their skills, and compete on a leaderboard.

The application must be a REAL full-stack application, not a static frontend or simple AI chatbot.

# 10. GEMINI AI ANALYSIS

Create a backend-only Gemini service.

Endpoint:

POST /api/ai/analyze-mission

The frontend must NEVER call Gemini directly.

The backend should send:

* Mission information
* User answer
* User findings
* Score
* Previous performance
* Mission category

to Gemini.

Gemini must return structured JSON.

Use Zod to validate the AI response.

Example schema:

{
"riskLevel": "HIGH",
"score": 85,
"correctFindings": [
"Suspicious sender domain",
"Urgent credential request"
],
"missedFindings": [
"URL mismatch"
],
"explanation": "The message contains several phishing indicators.",
"recommendations": [
"Verify the sender domain",
"Avoid clicking suspicious links"
],
"nextRecommendedTopic": "URL Safety",
"encouragement": "Good investigation. Improve your URL analysis."
}

Validate this response using Zod.

If Gemini fails, provide a safe fallback response so the application remains functional.
